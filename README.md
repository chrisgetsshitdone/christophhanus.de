# christophhanus.de

Persönliche Website von Christoph Oliver Hanus. Statisches HTML/CSS, gehostet über GitHub Pages.

- `index.html` – Home page
- `imprint.html`, `privacy.html` – Legal (Impressum, Datenschutz)
- `style.css` – gemeinsames Stylesheet
- `fonts/` – lokal gehostete Schriften (Unbounded, Space Grotesk, JetBrains Mono; SIL Open Font License)
- `CNAME` – eigene Domain für GitHub Pages

Lokal ansehen: `python3 -m http.server 8000` und http://localhost:8000 öffnen.
